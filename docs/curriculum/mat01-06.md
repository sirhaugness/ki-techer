# MAT01-06 — læreplangrunnlag

Kontrollert mot Udir 10. oktober 2026. Original ordlyd er nynorsk. Oppgaver og UI bruker bokmål. Dette er offentlig fastsatte kompetansemål; ferdighets-ID-ene i koden er våre egne, ikke Udirs API-ID-er.

## Etter 3. trinn (forkunnskaper)

- bruke formålstenlege strategiar for addisjon og subtraksjon til å lage og løyse problem frå leik og kvardag
- forklare og utforske samanhengar mellom addisjon og subtraksjon i hovudrekning og skriftleg rekning
- beskrive og utforske multiplikasjon ved teljing og gruppering
- bruke dobling og halvering i hovudrekning og skriftleg rekning
- bruke multiplikasjon og divisjon til å lage og løyse problem frå leik og kvardag
- bruke talsymbol, tekst, tabellar, teikning og konkret til å representere multiplikasjon på ulike måtar og omsetje mellom dei ulike representasjonane
- bruke kommutative, assosiative og distributive eigenskapar ved multiplikasjon i hovudrekning og skriftleg rekning
- bruke likskaps- og ulikskapsteikn som relasjonelle symbol for å samanlikne storleikar, mengder, uttrykk og tal
- bruke talsymbol, teikning og konkret for å utforske likevekt og omsetje mellom dei ulike representasjonane
- måle areal i praktiske situasjonar med ikkje-standardiserte og standardiserte måleiningar
- eksperimentere med, namngi og plassere punkt i koordinatsystemet
- lage og følgje reglar og trinnvise instruksjonar i leik og spel knytte til koordinatsystemet

## Etter 4. trinn (alle mål dekkes av ferdighetsgrafen)

- utforske og bruke målings- og delingsdivisjon i praktiske situasjonar
- bruke tal, tekst, teikning og konkret for å utforske divisjon på ulike måtar og omsetje mellom dei ulike representasjonane
- bruke og forklare ulike divisjonsstrategiar
- bruke hovudrekning og skriftleg rekning til å utforske og forklare samanhengar mellom dei fire rekneartane
- estimere, gjere overslag, forklare tenkjemåtar og vurdere kritisk eigne og andre sine modellar og løysingar i arbeid med praktiske situasjonar
- lage rekneuttrykk til praktiske situasjonar og finne praktiske situasjonar som passar til oppgitte rekneuttrykk
- beskrive og utforske eigenskapar ved to- og tredimensjonale figurar ved å bruke vinklar, kantar, hjørne og flater
- måle volum i praktiske situasjonar med ikkje-standardiserte og standardiserte måleiningar og samtale om resultata
- beskrive og utforske strukturar og mønster i leik og spel
- lage algoritmar og uttrykkje dei ved bruk av variablar, vilkår og lykkjer

## Etter 5. trinn (videre arbeid, ikke del av M2-grafen)

- bruke tal, teikning og konkret til å beskrive og utforske samanhengar mellom brøkar, desimaltal og prosent
- beskrive brøk som del av ein heil, som del av ei mengd, som ein divisjon og som tal på tallinja
- bruke tal, tekst, teikning, konkret og praktiske situasjonar for å representere brøkar og kunne omsetje mellom dei ulike representasjonane
- utvikle og bruke ulike strategiar for rekning med positive tal og brøk og forklare tenkjemåtane sine
- formulere og løyse problem som har med brøk å gjere
- utforske og beskrive tilfeldigheit og sannsyn i spel og praktiske situasjonar, og knyte det til brøk
- bruke tal, tekst, teikning og konkret til å løyse likningar og teste og forklare løysingar
- bruke rekneark for å lage og løyse oppgåver som handlar om personleg økonomi
- lage og løyse oppgåver som handlar om tid
- lage og programmere algoritmar med bruk av variablar, vilkår og lykkjer

## Kjerneelementer — pedagogisk bruk

Utforsking og problemløsning: bruk flere fremgangsmåter. Modellering og anvendelser: knytt uttrykk til situasjoner og vurder om løsningen passer. Resonnering og argumentasjon: be eleven forklare. Representasjon og kommunikasjon: oversett mellom konkrete ting, tegninger og symboler. Abstraksjon og generalisering: la eleven oppdage mønstre. Matematiske kunnskapsområder: tall, algebra, geometri, statistikk og sannsyn.
