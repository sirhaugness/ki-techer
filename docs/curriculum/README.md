# Læreplangrunnlag

[MAT01-06](mat01-06.md) inneholder måltekst og kilder. Målene etter 3. og 4. trinn ble kontrollert på nytt mot Udir 20. oktober 2026 ved kapittelrevisjonen. Det er ingen ny kontroll av hele ferdighetsgrafens runtime-dekning.

[Kapittelpedagogikken](chapter-pedagogy.md) knytter hvert målområde til de 20 oppgavene i Darth Vaders felle og skiller areal som forkunnskap fra volum etter 4. trinn. [SPEC](../SPEC.md) er kanonisk for produktretningen. Kapittelplanen dekker utvalgte mål, ikke hele skoleåret.
